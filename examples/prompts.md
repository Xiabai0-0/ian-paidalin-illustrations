# 派大林 IP 校准样图 Prompts

这 8 组校准任务用于验证角色在不同构图中的身份、动作和视觉语言。每张都使用：

- 16:9 横版纯白画布。
- `paidalin-illustrations/assets/ip-reference/paidalin-turnaround.png` 作为直接身份参考（就位前退回 `paidalin-character-sheet.png`）。
- 黑色细手绘线稿，大量留白；角色保留粉色身体、深蓝帽斗、金链与珊瑚红小爱心。
- 派大林亲手完成核心动作。
- 只使用给定中英文短标签，不添加标题。

## 01 内容工作台 / Workflow

派大林站在一台低科技纸张工作台前，把左侧皱巴巴的素材纸拆开、剪短、重新排列，右侧吐出一页清爽成稿。构图从左到右，但不要画成流程图。

标签：`原始素材 RAW` / `拆解` / `重组` / `可发布 READY`

## 02 逻辑维修 / 系统局部

一台只露出局部的“观点机器”有一块齿轮脱落。派大林半蹲，用放大镜查证、用法杖螺丝刀修复断裂逻辑，旁边放着一张证据卡。

标签：`断点 BUG` / `证据` / `修复 FIX` / `逻辑`

## 03 草稿前后 / 前后对比

左侧桌面堆满混乱草稿和重复句，右侧只留一页清晰表达。派大林处于中间，用红笔删除赘词，把唯一关键句推向右侧。

标签：`乱 DRAFT` / `删` / `重点 KEY` / `清晰 CLEAR`

## 04 卡住到想通 / 角色状态

用四个疏朗连续姿势表现同一个派大林：面对便签云卡住、安静观察、在分镜板上重画、最后轻微点头想通。不要画表情包格子。

标签：`卡住 STUCK` / `观察` / `重画` / `想通 AHA`

## 05 证据承重 / 概念隐喻

一个写着观点的小平台摇摇欲坠。派大林把一块块证据板塞进平台下方作为支撑，平台从倾斜变稳定；荒诞但物理关系成立。

标签：`观点 CLAIM` / `证据 EVIDENCE` / `承重` / `可信 TRUST`

## 06 方法搭层 / 方法分层

派大林从底部开始搭一个不规则悬浮纸砖结构：事实是底座，洞察是中层，表达是上层，最上方放一张待发布卡。不要正式金字塔。

标签：`事实 FACT` / `洞察 INSIGHT` / `表达 STORY` / `发布 GO`

## 07 选题到发布 / 地图路线

一条由胶带贴出的弯曲路线穿过四个检查点。派大林一边前进一边用红笔校验节点，并把一个错误方向牌转回正确方向。

标签：`选题 TOPIC` / `验证 CHECK` / `打磨 EDIT` / `发布 LIVE`

## 08 修改完成 / 小漫画分镜

三格开放式小漫画：第一格派大林交出偏题初稿；第二格他重新剪贴结构；第三格成稿站稳，他安静地做一个小确认手势。分格边线不完整、留白充足。

标签：`初稿 V1` / `偏了` / `修改 REVISE` / `完成 DONE`
