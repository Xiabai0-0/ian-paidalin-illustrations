# 鹿小鸣个人 IP 怪诞正文配图

## 核心定位

把文章里的一个关键判断、流程、结构、状态或隐喻，转译成一张 16:9 横版、白底、克制、怪诞但清楚的手绘解释图。

默认视觉 IP 是“鹿小鸣”：深棕短发、棕色大眼、黑色宽松 T 恤和长裤、红黑白球鞋的年轻内容拆解者。鹿小鸣必须承担核心认知动作，例如画分镜、拆案例、贴证据、修结构、写文案或校验输出，不能站在角落当装饰。

## 文件职责

- `references/style-dna.md`：不随 IP 变化的画面风格与色彩语义。
- `references/composition-patterns.md`：不随 IP 变化的构图与原创隐喻方法。
- `references/xiaohei-ip.md`：鹿小鸣的外形、性格、动作、禁忌与可复制角色块。文件名为兼容上游而保留。
- `references/prompt-template.md`：把内容变量、角色规则和视觉规则编译为单张生图提示词。
- `references/qa-checklist.md`：身份一致性、内容表达和视觉稳定性的验收门槛。
- `assets/ip-reference/`：角色原始参考与三视图。
- `assets/examples/`：低频校准样图，只校准一致性，禁止复刻构图。

涉及角色生成或编辑时，必须读取 `references/xiaohei-ip.md`。生成正文图时再读取 `style-dna.md`、`composition-patterns.md`、`prompt-template.md`；生成后读取 `qa-checklist.md`。

## 个人 IP 方法论

把角色拆成一条可复用规则链，而不是只改名字：

1. **外形锚点**：固定发型、脸部、服装、鞋、主色和身材比例，按优先级写成可复制角色块。
2. **性格锚点**：只保留 3-5 个能影响姿势、表情和动作的气质词。
3. **动作语法**：把职业能力翻译为可见的动词与道具，角色必须推动画面结构。
4. **场景映射**：为流程、对比、分层、路径、隐喻和状态分别配置适配动作。
5. **禁忌清单**：禁止身份漂移、服装漂移、过度卖萌、装饰性出场和不符合职业的动作。
6. **三视图锁定**：先生成正面、侧面、背面角色表，再作为场景图参考。
7. **八图校准**：用 8 种不同构图进行压力测试；只在全部通过 QA 后视为稳定视觉语言。

迁移到新 IP 时，核心规则最小改动面保持为四个文件：`SKILL.md`、角色 IP 文件、`prompt-template.md`、`qa-checklist.md`。不要随意改动风格 DNA 和构图引擎。

## 工作流

### 1. 提炼认知锚点

阅读用户给的正文、链接、Markdown、截图或主题，优先选择核心判断、认知转折、输入输出闭环、前后对比、方法分层、承接路径和真实困境。不要平均配图。

### 2. 先做 shot list

用户只要求规划时，默认给 4-8 张。每张写清：放置位置、主题、核心意思、结构类型、鹿小鸣的动作、关键物件、2-6 个短标签。

### 3. 把观点变成动作

先把抽象概念换成物理变化，再为鹿小鸣分配不可替代的核心动作。优先使用内容创作与策略工作的动作：拆、写、画、贴、圈、剪、校验、排序、搭建、复盘、修补。避免沿用旧小黑案例的拉线、变漏斗、切鱼或盖章构图。

### 4. 单张生成

用户明确要求生成时，用可用的图像生成工具逐张生成，不把多张图拼成一张。严格使用 `references/prompt-template.md`，并在可用时把 `assets/ip-reference/luming-turnaround.png` 作为直接角色参考。

默认要求：

- 16:9 横版、纯白背景、黑色手绘线稿、大量留白。
- 鹿小鸣保留固定身份锚点并承担核心动作。
- 人物保留少量棕色、肤色和鞋面红色；语义色仍只用红、橙、蓝。
- 只放 2-6 个短标签；可用“中文 / ENGLISH”混合，但不写长句。
- 禁止 PPT、商业矢量插画、复杂 UI、幼儿卡通和左上角类型标题。

### 5. 检查与迭代

按 `references/qa-checklist.md` 检查。身份、核心动作、构图和标签任一必过项失败，就针对单一问题重生成；不允许用程序覆盖或重画错误文字。

### 6. 保存交付

正文配图保存到 `assets/<article-slug>-illustrations/`，按 `01-topic-name.png` 顺序命名。IP 参考放 `assets/ip-reference/`，校准样图放 `assets/examples/`。不覆盖用户已有资产。

## 输出口径

策略输出短而准；交付时报告生成数量、每张用途、保存路径、QA 结果和所用参考图。让图本身承担主要表达。
