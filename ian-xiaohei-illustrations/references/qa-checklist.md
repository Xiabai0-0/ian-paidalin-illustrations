# 鹿小鸣配图 QA Checklist

## A. 硬性必过项

### 画布与风格

- [ ] 16:9 横版，纯白背景。
- [ ] 黑色细手绘线为主，线条轻微抖动但不脏。
- [ ] 主体约占 40%-60%，至少 35% 留白。
- [ ] 不像 PPT、正式流程图、商业矢量插画、UI 或儿童海报。

### IP 身份

- [ ] 是同一个鹿小鸣：年轻东亚男性、深棕蓬松短发、棕色大眼、圆润偏椭圆脸。
- [ ] 固定穿黑色宽松短袖 T 恤、黑色宽松长裤、黑白红低帮球鞋。
- [ ] 身材偏瘦，约 5.5-6.5 头身；不是 2-3 头身萌系 Q 版。
- [ ] 无眼镜、无帽子、无首饰、无 Logo、无服装漂移。
- [ ] 鹿小鸣承担核心动作；删掉角色后，画面含义应明显失效。

### 内容与动作

- [ ] 一张图只表达一个认知锚点。
- [ ] 动作属于“拆解、写作、分镜、查证、排序、搭建、修复、复盘”之一，并且服务核心意思。
- [ ] 使用当前主题的新物理隐喻，没有复用旧小黑的拉线、漏斗、切鱼、盖章等构图。
- [ ] 道具不超过 4 类，结构不超过 5 个视觉节点。

### 文字与颜色

- [ ] 只有 2-6 个短标签，每个尽量 1-6 个汉字或 1-2 个英文词。
- [ ] 指定标签逐字正确，无额外标题、乱码或长句。
- [ ] 中英文混排有语义：中文说概念，英文说状态或动作，不做重复翻译堆砌。
- [ ] 橙色只用于主路径；红色只用于警告、纠错、结果与鞋面识别；蓝色只用于证据、反馈或次级状态。

## B. 三视图校准

- [ ] FRONT / SIDE / BACK 是同一个人、同一比例、同一身高。
- [ ] 三个视角的发型轮廓、T 恤长度、裤脚堆叠和鞋底厚度一致。
- [ ] 背面无多余图案；侧面鼻梁、下巴与发尾保持简洁。
- [ ] 只有三个完整全身视角，无额外半身像、表情格或道具。

## C. 八图压力测试矩阵

校准样图必须覆盖且各不重复：

1. Workflow：写作工作台。
2. 系统局部：修复逻辑模块。
3. 前后对比：混乱草稿到清晰表达。
4. 角色状态：卡住到想通。
5. 概念隐喻：证据给观点承重。
6. 方法分层：从底层搭内容结构。
7. 地图路线：选题到发布的校验路径。
8. 小漫画分镜：失败、修改、完成。

八张中至少六张通过全部 A 项，剩余两张只允许出现轻微文字误差；角色身份、服装、动作主体和 16:9 比例不得失败。

## D. 失败信号与处理

- **身份漂移**：只锁角色块重生成，不改变场景。
- **像普通动漫少年**：加强黑色宽松穿搭、红黑白球鞋与内容拆解动作。
- **动作太弱**：删除指向/围观姿势，让角色亲手造成结构变化。
- **太可爱**：强调 calm、serious、subtle humor；降低头身夸张和表情幅度。
- **太 PPT**：删标题、边框、整齐网格和多余箭头，改成单一物理场景。
- **太满**：删节点、道具和标签，保留一个动作与 2-4 个物件。
- **文字错误**：优先用更短标签重生成；不得用程序覆盖文字。
- **像旧案例**：保留观点，替换主物件与动作语法。

## E. 交付门槛

高质量图应让读者先认出鹿小鸣正在“动手解决一个内容问题”，再在 1 秒内看懂核心判断。若第一眼只像动漫人物海报、教程页或换皮小黑图，则不合格。
