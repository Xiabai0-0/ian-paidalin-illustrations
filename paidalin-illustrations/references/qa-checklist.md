# 派大林配图 QA Checklist

## A. 硬性必过项

### 画布与风格

- [ ] 16:9 横版，纯白背景。
- [ ] 黑色细手绘线为主，线条轻微抖动但不脏；不是 3D 渲染、厚涂或商业插画质感。
- [ ] 主体约占 40%-60%，至少 35% 留白。
- [ ] 不像 PPT、正式流程图、商业矢量插画、UI 或儿童海报。
- [ ] 与 `assets/examples/` 校准样图并排对比：眼睛画法、线稿密度、上色平涂度一致，没有绘本化 glossy 大眼或精修质感回归。

### IP 身份

- [ ] 是同一个派大林：粉色海星身体、圆钝五角轮廓（圆头顶、两侧短圆臂、底部短圆小腿）、圆润无脖颈。
- [ ] 圆大眼带高光、弧形细眉、温和微笑、脸颊腮红。
- [ ] 固定深蓝宽檐弯角巫师帽：银线藤蔓刺绣、帽檐铜色护目镜装饰、帽尖卷曲成螺旋。
- [ ] 固定深蓝高立领披肩与层叠银绣斗篷，胸口纹章扣配金链宝石挂饰。
- [ ] 右眼单片金边眼镜，细链垂至衣领；不换边、不配对成双。
- [ ] 右手水晶法杖（深色木柄缠藤蔓、顶端蓝水晶）；临时持其他工具时法杖仍在画面内。
- [ ] 身侧漂浮一颗珊瑚红小爱心，不缺席、不放大成主视觉。
- [ ] 不是派大星：不穿花短裤、不咧嘴傻笑、不展平海星肢、臂端无人类五指。
- [ ] 不是 2-3 头身萌系 Q 版、肌肉英雄、偶像海报或表情包。
- [ ] 派大林承担核心动作；删掉角色后，画面含义应明显失效。

### 内容与动作

- [ ] 一张图只表达一个认知锚点。
- [ ] 动作属于“拆解、写作、分镜、查证、排序、搭建、修复、复盘”之一，并且服务核心意思。
- [ ] 魔法只让动作因果可见：没有光效烟花、符文阵列或特效炫技。
- [ ] 使用当前主题的新物理隐喻，没有复用旧小黑与旧鹿小鸣的拉线、漏斗、切鱼、盖章等构图。
- [ ] 道具不超过 4 类，结构不超过 5 个视觉节点。

### 文字与颜色

- [ ] 只有 2-6 个短标签，每个尽量 1-6 个汉字或 1-2 个英文词。
- [ ] 指定标签逐字正确，无额外标题、乱码或长句。
- [ ] 中英文混排有语义：中文说概念，英文说状态或动作，不做重复翻译堆砌。
- [ ] 角色识别色不参与语义色：粉色身体与深蓝帽斗、金链、珊瑚红爱心保持稳定。
- [ ] 橙色只用于主路径；红色只用于警告、纠错与结果，不含角色爱心；蓝色只用于证据、反馈或次级状态，不重绘帽斗。

## B. 三视图校准

- [ ] FRONT / SIDE / BACK 是同一个角色、同一比例、同一身高。
- [ ] 三个视角的帽檐弧线、螺旋帽尖、单片眼镜与细链、斗篷层叠厚度、法杖与爱心位置一致。
- [ ] 背面无多余图案（帽尖螺旋与斗篷银绣纹样除外）；侧面身体厚度圆润、帽檐弧线清晰。
- [ ] 只有三个完整全身视角，无额外半身像、表情格；道具只有法杖。

## C. 八图压力测试矩阵

校准样图必须覆盖且各不重复：

1. Workflow：写作工作台。
2. 系统局部：修复逻辑模块。
3. 前后对比：混乱草稿到清晰表达。
4. 角色状态：卡住到想通。
5. 概念隐喻：证据给观点承重。
6. 方法分层：从底层搭内容结构。
7. 地图路线：选题到发布的校验路径。
8. 小漫画分镜：失败、修改、完成。

八张中至少六张通过全部 A 项，剩余两张只允许出现轻微文字误差；角色身份、服装、动作主体和 16:9 比例不得失败。

## D. 失败信号与处理

- **身份漂移**：只锁角色块重生成，不改变场景。
- **像派大星或普通海星卡通**：加强巫师帽、斗篷、单片眼镜、法杖与内容拆解动作，收敛表情为温和微笑。
- **像 3D 渲染图**：重申白底黑线手绘风格重生成；参考图只用于锁定形象。
- **像绘本插画或 glossy 大眼**：确认已挂 Image 2 校准样图，以它的眼睛画法与线稿密度为准，重申 STYLE RULES 草图规则后重生成。
- **动作太弱**：删除指向/围观姿势，让角色亲手造成结构变化。
- **魔法太炫**：删除光效、烟花与悬浮符文阵列，魔法只体现为物件自动化的因果。
- **法杖消失**：补回法杖（手持或立于身侧），并确认爱心在场。
- **太可爱**：强调 calm、serious、subtle humor；降低头身夸张和表情幅度。
- **太 PPT**：删标题、边框、整齐网格和多余箭头，改成单一物理场景。
- **太满**：删节点、道具和标签，保留一个动作与 2-4 个物件。
- **文字错误**：优先用更短标签重生成；不得用程序覆盖文字。
- **像旧案例**：保留观点，替换主物件与动作语法。

## E. 交付门槛

高质量图应让读者先认出派大林正在“动手解决一个内容问题”，再在 1 秒内看懂核心判断。若第一眼只像卡通巫师海报、教程页、换皮派大星图或 3D 渲染图，则不合格。
